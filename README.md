# Supriya Khadake — Portfolio

**Live site:** [supriyakhadake.github.io](https://supriyakhadake.github.io/)

Growth & marketing analytics portfolio — Data Science Leader, Growth & Marketing, 10 years in fintech (8 at PayPal, plus consulting for American Express). Built to show working analytics tools, not slides: an incrementality budget allocator, an A/B test readout with real significance testing, and measurement case studies (matched-market difference-in-differences, holdout testing).

- **Hero** — headline, role, and a live preview of the Incrementality tool
- **About** — background, channel and cross-functional experience, impact stats
- **Work samples** — two linked live tools (screenshots + working links) and a full case study
- **Contact** — email + LinkedIn

## Method

Every number on this site and in its linked tools is computed by deterministic code — conversion rates, lift, z-statistics, p-values, ROI. Claude is used for synthesis: turning verified numbers into plain-English executive narrative. The math is never AI-generated; the write-up is never hand-typed. That division is the actual thesis of the portfolio, not just a build note.
